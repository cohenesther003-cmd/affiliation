# Affiliation Pipeline — Project Context

## What this project is
Automated affiliate marketing pipeline that discovers Amazon products from multiple sources, validates them, and publishes them to a Hebrew product store on GitHub Pages. Sources include Amazon Best Sellers, affiliate link pages (byotools.me), a Telegram channel, and TikTok creator storefronts. Future phases will transform source videos into Hebrew TikTok content, distribute them, and track performance.

## Owner

## Tech stack
- **Language**: Python
- **Database**: SQLite (`data/products.db`) — never switch to JSON or CSV
- **Scraping**: Playwright (headless Chromium)
- **Amazon**: Playwright scraping of product pages (no PA-API — not yet eligible; requires 10 sales first)
- **Config**: `config.yaml` (loaded by `config.py`) — all thresholds and settings live here
- **Env vars**: `.env` file (never commit, template is `.env.example`)
- **Dashboard**: Flask app (`app.py`) on port 5001 — run with `python app.py`
- **Public site**: GitHub Pages at `https://cohenesther003-cmd.github.io/affiliation/` — generated by `export_page.py`
- **Hebrew translation**: Uses `claude --print -p "..."` CLI (already authenticated, no API key needed)

## Product lifecycle statuses
- `discovered` — added to DB; scraping not yet done OR scrape was blocked (will be retried next validate run)
- `validated` — Amazon page scraped successfully: name, price, rating, shipping confirmed
- `ready_for_video` — passed all filters in config.yaml (shown on public site)
- `filtered_out` — **only set by `filter.py`**: product failed a quality rule (rating, reviews, price, Israel shipping). Never set for scrape failures.
- `unavailable` — out of stock; auto-restored to `ready_for_video` if back in stock on next refresh
- `video_ready` — Phase 2 complete: video downloaded + Hebrew script generated
- `video_failed` — Phase 2 attempted but failed

**Important:** `amazon_api.py` (validate phase) leaves products as `discovered` when scraping fails (bot block, CAPTCHA). Only `filter.py` ever writes `filtered_out`. This ensures scrape failures are always retryable.

## Key behaviors

- **Delta scraping**: `scraper.py`, `byotools_scrape.py`, and `amitkapit_scrape.py` all skip ASINs already in the DB
- **ILS price handling**: scraper runs from an Israeli IP → Amazon shows ILS prices → auto-converted to USD at ~3.65 rate. Run `refresh_products.py` after any bulk scrape to correct prices.
- **Price mismatch vs. Amazon.com**: prices on the site will look lower than Amazon.com's USD prices. This is expected and correct — Amazon charges less in ILS than the USD equivalent (local pricing strategy). A logged-in US Amazon account sees the US USD price ($60), while an Israeli customer (our target audience) actually pays the ILS price (~$47). Our site shows the ILS-converted USD price, which is what Israeli shoppers actually pay. Do NOT treat this as a bug.
- **Price scraping (amazon_api.py + refresh_products.py)**: uses `.priceToPay` — Amazon's class for the actual selling price. **Never use `.basisPrice`** (crossed-out list price). When Amazon shows both a Prime price and a regular price, they both appear as `.priceToPay` elements — **Prime first, regular last**. Always take the **last** `.priceToPay` in the buy-box container to get the regular (non-Prime) price that most Israeli users pay. ILS prices are parsed from `inner_text()` directly with whitespace collapsed first, so split renders like `ILS116\n.\n63` parse correctly as `ILS116.63`.
- **Shipping classification**: `free_with_prime` is only used when free shipping is exclusively for Prime members (page contains "exclusively for" + "with prime"). If the regular price also has free shipping, classify as `free`. Never misclassify a product as `free_with_prime` just because a Prime price option exists on the page.
- **Availability detection**: checks for unavailability phrases AND absence of `#add-to-cart-button`. A product with no Add to Cart button has no active buy box → mark as `unavailable`. Do NOT rely on text phrases alone — Amazon can show an unavailable product without them.
- **Affiliate links**: all links use the format `https://www.amazon.com/dp/{ASIN}/?tag=eskl20-20` (no language parameter — `amazon.com` does not support `he_IL`).
- **Validate phase**: when `_scrape_product()` returns None (blocked/CAPTCHA), the product stays `discovered` for retry — it is NOT set to `filtered_out`. Only `filter.py` writes `filtered_out`.
- **Daily refresh (`refresh_products.py`)**: runs daily at 8:00 AM (local time) via launchd. Re-scrapes all `ready_for_video` products for price/availability/shipping. Auto-runs filter + exports site + git push when anything changes. Writes email report to `data/pending_reports/` (sent by mail-sender agent).
- **Telegram pipeline**: `telegram_scrape.py` polls `t.me/s/haregakaniti` every 6h. New ASINs → `discovered`, `category='telegram'`. `run_telegram_pipeline.sh` runs the full pipeline end-to-end. `telegram_report.py` writes a Hebrew summary to `data/pending_reports/` (sent by mail-sender agent).
- **Mail-sender agent**: `send_pending_reports.py` runs every 30 min via launchd (`me.affiliation.mail-sender`). Scans `data/pending_reports/*.json`, sends each queued email via Gmail SMTP, deletes the file. Credentials: `GMAIL_USER` + `GMAIL_APP_PASSWORD` in `.env`. Never call this from inside a pipeline — pipelines only write to `data/pending_reports/`.
- **TikTok creator pipeline** (`amitkapit_scrape.py`): 1) Download creator videos via Apify MCP → save dataset as local JSON; 2) run script with `--dataset-id`, `--username`, `--category`, `--output` flags; 3) extracts Amazon links from descriptions (resolves short links → ASIN); 4) for videos without links, tries Amazon search by title; 5) scrapes product pages; 6) saves ships-to-Israel products to DB; 7) writes ranked CSV. Then run validate → filter → translate → enrich → export pipeline.
- **Top category**: 20 hand-picked byotools products with highest @byotools TikTok view counts (≥5K views, rating ≥ 4, ships Israel, price ≤ $100). `source_video_url` points to the TikTok video. Shown with ⭐ TOP badge. Priority for Phase 2 video creation.
- **Image scraping**: `amazon_api.py` captures `image_url` for new products. Run `enrich_products.py` to backfill.
- **Hebrew descriptions**: `enrich_products.py` uses `claude --print -p` CLI. Forbids niqqud, forces metric units. Resets descriptions shorter than 200 chars on each run.
- **Hebrew name translation**: `translate_names.py` sends 15 names per batch to Claude CLI. Enforces natural Hebrew terminology, forbids niqqud, converts imperial units. Use `--retranslate` to clear and re-translate everything.
- **Rating update**: `python update_ratings.py` fills in rating=0 products. 2.5–4.5s delays + cookie re-warm every 30 products.
- **Israel shipping verification**: `python verify_israel_shipping.py` re-checks all `ready_for_video` products. Re-sets location every 5 products.

## How to run
```bash
cd ~/affiliation && source .venv/bin/activate

# Amazon Best Sellers pipeline
python main.py --url "https://www.amazon.com/Best-Sellers-Tools-Home-Improvement/zgbs/hi/"

# byotools pipeline
python byotools_scrape.py

# TikTok creator pipeline (e.g. @bk_owner)
# Step 1: scrape TikTok videos via Apify MCP → save dataset JSON locally
# Step 2:
python amitkapit_scrape.py --dataset-id bk_owner_dataset.json --username bk_owner --category bk_owner
# Step 3: run full pipeline
python main.py --phase validate && python main.py --phase filter && python translate_names.py && python enrich_products.py

# Fix missing ratings
python update_ratings.py

# Fix products where name shows as raw ASIN code
python fix_missing_names.py

# Re-verify Israel shipping
python verify_israel_shipping.py

# Backfill product images + Hebrew descriptions (uses claude CLI, no API key needed)
python enrich_products.py

# Translate product names to Hebrew in batches
python translate_names.py

# Regenerate entire public site and push to GitHub Pages
python export_page.py && git add docs/ && git commit -m "Update products" && git push

# Flask dashboard (internal use)
python app.py   # open http://localhost:5001
```
