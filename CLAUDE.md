# Affiliation Pipeline — Project Context

## What this project is
Automated affiliate marketing pipeline that discovers Amazon products, validates them, and publishes them to a shareable product page. Sources include Amazon Best Sellers and third-party affiliate link pages (e.g. byotools.me). Future phases will transform source videos into Hebrew TikTok content, distribute them, and track performance.

## Owner
Esther Cohen — non-coder. Keep explanations simple, avoid jargon. All configurable settings must stay in `config.yaml`, not hardcoded in Python files.

## Tech stack
- **Language**: Python
- **Database**: SQLite (`data/products.db`) — never switch to JSON or CSV
- **Scraping**: Playwright (headless Chromium)
- **Amazon**: Playwright scraping of product pages (no PA-API — not yet eligible; requires 10 sales first)
- **Config**: `config.yaml` (loaded by `config.py`) — all thresholds and settings live here
- **Env vars**: `.env` file (never commit, template is `.env.example`)
- **Dashboard**: Flask app (`app.py`) on port 5001 — run with `python app.py`
- **Public page**: GitHub Pages at `https://cohenesther003-cmd.github.io/affiliation/` — generated by `export_page.py`

## Database schema (products table)
| Column | Type | Notes |
|--------|------|-------|
| asin | TEXT UNIQUE | Amazon product ID |
| name | TEXT | Product title |
| category | TEXT | e.g. Tools, Garden, byotools |
| rating | REAL | Star rating (0 if unknown) |
| review_count | INTEGER | Number of reviews (0 if unknown) |
| price_usd | REAL | In USD (ILS prices converted at ~3.65 rate) |
| ships_to_israel | INTEGER | 0 or 1 |
| affiliate_link | TEXT | Built as amazon.com/dp/{ASIN}/?tag={PARTNER_TAG} |
| source_video_url | TEXT | NULL until Phase 2 |
| status | TEXT | discovered → validated → ready_for_video → filtered_out |
| discovered_at | TEXT | ISO timestamp |
| updated_at | TEXT | ISO timestamp |

## Product lifecycle statuses
- `discovered` — scraped from Amazon, not yet validated
- `validated` — product page scraped, rating/price/availability confirmed
- `ready_for_video` — passed all filters in config.yaml
- `filtered_out` — failed one or more filters

## Key behaviors
- **Delta scraping**: both `scraper.py` and `byotools_scrape.py` skip ASINs already in the DB — only new products are scraped on repeat runs
- **ILS price handling**: scraper runs from Israeli IP, so Amazon shows prices in ILS. Prices are auto-converted to USD at ~3.65 rate. ILS price = confirmed ships to Israel.
- **byotools pipeline**: scrapes byotools.me/byotlinks → for Amazon links resolves ASIN directly → for non-Amazon links searches Amazon by product name → scrapes product page
- **GitHub Pages**: run `python export_page.py` then `git add docs/index.html && git commit && git push` to update the public page

## How to run
```bash
cd ~/affiliation && source .venv/bin/activate

# Amazon Best Sellers pipeline
python main.py --url "https://www.amazon.com/Best-Sellers-Tools-Home-Improvement/zgbs/hi/"

# byotools pipeline
python byotools_scrape.py

# Flask dashboard
python app.py   # open http://localhost:5001

# Update public GitHub Pages
python export_page.py && git add docs/index.html && git commit -m "Update products" && git push
```
