# Affiliation Pipeline — Project Context

## What this project is
Automated affiliate marketing pipeline that discovers Amazon products, validates them, transforms source videos into Hebrew TikTok content, distributes them, and tracks performance.

## Owner
Esther Cohen — non-coder. Keep explanations simple, avoid jargon. All configurable settings must stay in `config.yaml`, not hardcoded in Python files.

## Tech stack
- **Language**: Python
- **Database**: SQLite (`data/products.db`) — never switch to JSON or CSV
- **Scraping**: Playwright (headless Chromium)
- **Amazon**: PA-API 5.0 via `python-amazon-paapi`
- **Config**: `config.yaml` (loaded by `config.py`) — all thresholds and settings live here
- **Env vars**: `.env` file (never commit, template is `.env.example`)

## Project phases

| Phase | Status | Description |
|-------|--------|-------------|
| 1 — Data & Validation | ✅ Built | Playwright scraper → Amazon PA-API → SQLite |
| 2 — Video Transformation | 🔜 Next | yt-dlp + GPT-4o Hebrew script + ElevenLabs voiceover + MoviePy editing |
| 3 — Distribution | 🔜 Planned | TikTok Content API + Spark Ads + Link-in-Bio |
| 4 — Analytics | 🔜 Planned | Amazon sales + TikTok ad spend → KPI tracking |

## Database schema (products table)
| Column | Type | Notes |
|--------|------|-------|
| asin | TEXT UNIQUE | Amazon product ID |
| name | TEXT | Product title |
| category | TEXT | e.g. Tools, Garden |
| rating | REAL | Star rating |
| review_count | INTEGER | Number of reviews |
| price_usd | REAL | |
| ships_to_israel | INTEGER | 0 or 1 |
| affiliate_link | TEXT | Generated by PA-API |
| source_video_url | TEXT | NULL until Phase 2 |
| status | TEXT | discovered → validated → ready_for_video → filtered_out |
| discovered_at | TEXT | ISO timestamp |
| updated_at | TEXT | ISO timestamp |

## Product lifecycle statuses
- `discovered` — scraped from Amazon, not yet validated
- `validated` — PA-API confirmed details
- `ready_for_video` — passed all filters in config.yaml
- `filtered_out` — failed one or more filters

## API keys needed
- **Phase 1**: `AMAZON_ACCESS_KEY`, `AMAZON_SECRET_KEY`, `AMAZON_PARTNER_TAG`
- **Phase 2**: `OPENAI_API_KEY`, `ELEVENLABS_API_KEY`
- **Phase 3**: `TIKTOK_CLIENT_KEY`, `TIKTOK_CLIENT_SECRET`

## Rules
- All filter logic must read from `CONFIG["filters"]` in `config.yaml` — never hardcode thresholds
- Never commit `.env` or `data/*.db`
- New phases go in `src/phase2/`, `src/phase3/`, etc.
- Keep CLI flags in `main.py` — Esther runs everything from the terminal with `python main.py`
